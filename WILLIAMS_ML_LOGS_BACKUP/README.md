# Williams %R + ML Strategy (Production V1)

## 🚀 Overview
This is the production-ready bundle for the **Williams %R + XGBoost + Regime Shield** strategy.
It includes a fully integrated:
- **Trading Engine**: Python-based bot connecting to Hyperliquid (Live & Paper).
- **ML Model**: Pre-trained XGBoost Classifier (`model_v1.json`) filtering for high-probability breakouts.
- **Regime Shield**: Trend filter (EMA 20/50) that blocks trades during choppy/adverse market conditions.
