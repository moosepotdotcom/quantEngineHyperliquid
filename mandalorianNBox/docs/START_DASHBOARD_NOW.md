# 🎛️ Start Your Dashboard - RIGHT NOW!

## 🚀 Quick Start (Copy & Paste)

### Step 1: Install Dashboard Packages

```bash
cd "/Users/alifiyaa/Downloads/ATC Bootcamp Code 2025"
source algotrader/bin/activate
pip install Flask flask-socketio python-socketio eventlet
```

### Step 2: Start Dashboard

```bash
cd dashboard
python app.py
```

**OR use the quick script:**
```bash
./START_DASHBOARD.sh
```

## 🌐 Access Dashboard

Once you see:
```
🚀 Starting Trading Bot Dashboard on http://127.0.0.1:5000
```

**Open your browser to:** http://127.0.0.1:5000

## 📊 What You'll See

The dashboard runs in your **terminal** and opens in your **browser**:

- **Terminal:** Shows server logs and status
- **Browser:** Shows the dashboard interface (Risk Control, Trading Log, etc.)

## 🛑 Stop Dashboard

Press `Ctrl+C` in the terminal
