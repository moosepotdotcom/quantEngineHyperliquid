## 🎯 Start Testing Now

### 1. Start Dashboard
```bash
./START_DASHBOARD_PLUG_PLAY.sh
```

### 2. Open Browser
```
http://127.0.0.1:5000
```

### 3. Go to "Backtest" Tab

### 4. Select:
- **Strategy**: Any of the 13 strategies
- **Data File**: Choose BTC or ETH data
- **Parameters**: Adjust as needed
- **Date Range**: Set start/end dates

### 5. Click "Run Backtest"

### 6. Review Results:
- Profit %
- Sharpe Ratio
- Win Rate
- Total Trades
- Max Drawdown
