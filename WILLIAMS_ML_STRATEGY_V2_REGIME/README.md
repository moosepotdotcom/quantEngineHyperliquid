
# Williams %R + ML Strategy V1 (Validated)

This strategy combines the **Williams %R** momentum indicator with an **XGBoost Classifier** to filter out low-probability trades.

## Key Performance (Validated Jan 2026)
- **Win Rate:** ~79.6% (Out-of-Sample Test on Jan 17-21, 2026)
- **Trade Frequency:** ~12-15 trades/day (Portfolio of 5 Coins)
- **Profitability:** +8.8% PnL (in 4 days)
- **Parameters:** Period 21, TP 0.7%, SL 1.5%.

## Strategy Logic
1.  **Indicator:** Williams %R (Period 21).
2.  **Signal:** Momentum Breakout (Crossing above -20 from below) or Breakdown (Crossing below -80 from above).
3.  **ML Filter:** An XGBoost model analyzes Market Context (RSI, ATR, Vol Change, EMA Dist) to confirm the trade.
4.  **Risk Management:**
    - **Take Profit:** 0.7% (Quick Scalp)
    - **Stop Loss:** 1.5% (Wide Stop to allow breathing room)
    - **Timeframe:** 5 Minutes (5m)

## Setup Instructions

### 1. Requirements
Ensure you have the required Python libraries:
```bash
pip install pandas numpy xgboost requests
```

### 2. Fetch Data
Use `fetch_data.py` to download the latest 5m data for the portfolio (BTC, ETH, SOL, AVAX, SUI).
```bash
python3 fetch_data.py
```
*Note: The strategy is optimized for 5m data.*

### 3. Backtest
Simulate the strategy on the downloaded data:
```bash
python3 backtest.py
```
This will generate a `trades.csv` log and print performance metrics.

### 4. Retrain Model (Optional)
If you want to update the model with new data:
```bash
python3 train_model.py
```
This will verify data availability and save a new `model_v1.json`.
